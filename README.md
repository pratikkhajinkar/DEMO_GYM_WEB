# Titan Forge - Elite Gym & Fitness Website

This repository contains the complete source code for the modern, high-conversion Gym & Fitness website.

## Features
- Ultra-modern Dark & Neon Crimson Aesthetic
- 100% Fully Responsive across Android, iPhone, iPad, and Desktop
- Dynamic Weekly Class Schedule with live day-by-day filters
- Interactive Monthly / Annual Membership pricing toggle with discount logic
- 1-Day VIP Pass booking modal & real-time toast alerts
- Accordion FAQ and athlete testimonials

## How to Deploy to GitHub Pages (Live in 1 minute):
1. Create a new repository on GitHub (e.g., `titan-forge-gym`).
2. Upload `index.html` to the repository root.
3. In GitHub, go to **Settings** -> **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your website will be live in 1-2 minutes at: `https://<your-username>.github.io/<repo-name>/`
